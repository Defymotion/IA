# programacion-plc

Skill para que Claude lea y modifique programas de PLC/HMI por XML (TIA Portal vía Openness; Schneider Machine Expert en beta).
Funciona junto con el watcher de [PLC IA](../../automatizaciones/plcia/): Claude deja trabajos en `C:\PLC_Bridge\inbox\` y el watcher exporta, importa y compila en TIA.

**Cargar:** comprimir esta carpeta (`programacion-plc/` con el `SKILL.md` adentro) y cargarla en Claude como skill.
**Pedir:** *"bajá el proyecto y fijate por qué no arranca la cinta"*, *"agregá un botón que mande el formato"*.
